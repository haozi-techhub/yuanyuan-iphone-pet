# 圆圆吧台精灵 · iPhone

把 iPhone 横放在桌上，让圆圆陪你工作、休息或玩一会儿。只支持左右两个横屏方向。第一次打开进入「自动表情」，每个动作播完后等 3–5 秒换下一个，35 个表情播完一轮再洗牌。切到「陪伴」等其他模式后，下次打开会继续用上次选的模式。

## 第一次怎么玩

首页中间是圆圆，右下是「聊聊」、隔空互动（眼睛）和「玩法」，右上可直接打开「设置」。5 秒没触摸时按钮淡出，轻点屏幕即可恢复。聊天或相机使用中会保留对应的结束入口。点「玩法」即可切换四种模式，小游戏和手势指南在「更多玩法」。

| 想做什么 | 怎么操作 |
| --- | --- |
| 戳圆圆、摸摸脸 | 第一戳会笑；每次间隔不超过约 1 秒，第二戳会惊讶，第三戳会生气，第八戳会触发专属动画：鼓腮憋气、瞪眼炸开火花，再瘪下来喘气。爆炸播完后可以重新开始。第一次戳到眼睛还会闭上对应的一侧。横向轻抚眼睛附近，它会眯眼、跟随手指。 |
| 点空白处换表情 | 在「自动表情」和「陪伴」模式，轻点脸以外的空白处会播放下一个常用表情，也会唤回隐藏的按钮。 |
| 双指换表情 | 陪伴或自动表情时，在圆圆脸上用两根手指一起向左滑看下一个，向右滑回上一个。只在 6 个常用表情里循环。 |
| 三指放彩带 | 在圆圆脸上用三根手指一起向上滑。也可从「更多玩法」下方的「彩蛋 → 庆祝」点按播放。 |
| 找指定表情 | 打开「玩法 → 更多玩法」，在下方按「常用、心情、动作、彩蛋」浏览。点一个会回到首页播；想看整套，在「更多玩法」打开「表情秀」。 |
| 和圆圆聊心情 | 点「聊聊」，说「我不开心了」或「我今天很开心」。圆圆会安慰你或邀请你继续分享，播报完会继续听。点「结束」或说「结束对话」退出。 |
| 戳泡泡、击掌、扔球 | 点「玩法 → 更多玩法」选游戏。触屏就能戳泡泡和击掌；扔球接球时，拖动球朝圆圆的手瞄准，松手投出，也可点「投给圆圆」。圆圆接住会把球抛回来，三球后结算。 |
| 开番茄钟 | 「玩法 → 更多玩法 → 番茄钟」。专注 25 分钟，可接 5 分钟休息。锁屏后继续计时，允许通知后会收到后台提醒。专注时玩扔球，计时也会继续。 |
| 听歌或换场景 | 「玩法」里切换模式，「更多玩法」里可以听圆圆唱歌。选中夜灯后，可在「更多玩法」设定定时。 |
| 隔空互动 | 点首页「聊聊」旁的眼睛，首次允许相机后，试着挥挥手。眼睛亮起表示相机已开，再点一次关闭。离开 App 到后台、进入夜灯或开始专注时自动关闭。 |
| 摇一摇、拍手 | 「更多玩法」里点对应入口，回到首页直接试。拍手和吹气需要麦克风权限。 |

夜灯和专注期间会暂停感应。相机画面只在设备上处理。在首页「设置」可调整主动问候、屏幕常亮、唤醒和音效；不用进设置才能开始玩。主动问候默认开启，早上和中午各有一次本机问候。

如果长时间把圆圆放在桌面上，可以在「设置 → 日常偏好」打开「省电显示」。圆圆会降低待机刷新频率并简化边缘光效，触摸和隔空互动仍优先保持响应。iPhone 开启低电量模式或设备过热时也会自动启用。

## 语音怎么配置

常见心情和语音动作不需要 Key。想扩展自由聊天或更换播报音色，可打开「设置 → 语音服务」。在「设置 → 名字与性格」可自定义宠物名字和性格。两个 Key 可以独立启用，保存在 iPhone 钥匙串，可测试、替换或移除。

| 配置 | 用途 | 数据怎么处理 |
| --- | --- | --- |
| 不填 Key | 本机转写和播报，支持常见情绪、问候和动作指令。 | 通过本地规则识别常见说法；可继续听你讲，但不会分析自由分享的具体细节。 |
| DeepSeek API Key | 按上下文生成自由聊天回复。 | 自由聊天会发送转写文字和最多 8 轮近期对话给 DeepSeek；历史存于 App 内存。 |
| 豆包语音 API Key | 云端实时转写和「团子」播报。配置方法见[豆包语音控制台](https://console.volcengine.com/speech/new/setting/apikeys?projectName=default)。 | 主动录音和待播报文本由火山引擎处理。团子音色遇到连接问题时会显示文字和提示，可重播。 |

可以直接问「台北明天天气怎么样」，也可以在语音服务中设置默认天气城市，再问「今天会下雨吗」。支持当前天气及今天、明天、后天预报，城市搜索使用 [Open-Meteo / GeoNames](https://open-meteo.com/en/docs/geocoding-api)。圆圆将 [MET Norway](https://docs.api.met.no/doc/locationforecast/HowTO.html) 的分时预报整理为语音摘要（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。

## 安装到自己的 iPhone

需要一台装有 Xcode 26 或更新版本的 Mac，以及运行 iOS 17 或更新版本的 iPhone。当前提供 Xcode 源码安装。

1. 先安装 [Git LFS](https://git-lfs.com/)，再下载源码和离线语音模型：

   ```bash
   git lfs install
   git clone https://github.com/haozi-techhub/yuanyuan-iphone-pet.git
   cd yuanyuan-iphone-pet
   git lfs pull
   open DesktopPet.xcodeproj
   ```

2. 连接并信任 iPhone。若系统提示，在 iPhone 的「设置 → 隐私与安全性」开启开发者模式。
3. 在 Xcode 的 `DesktopPet` 和 `PetLiveWidget` targets 中进入 **Signing & Capabilities**，启用自动签名，并选择同一个 Team。如果要更换 Bundle Identifier，将扩展的标识设为主 App 标识加 `.PetLiveWidget`。
4. 在 Xcode 工具栏选择自己的 iPhone，点 Run。免费 Personal Team 签名到期后，需要通过 Xcode 重新安装。

## 灵动岛与消息提醒

1. 打开圆圆后会自动开启实时陪伴。回到主屏幕查看灵动岛，锁屏后也可查看。可在「设置 → 灵动岛与通知」关闭陪伴。实时活动的显示位置和持续时间由 iOS 管理。
2. 在 iPhone 的「快捷指令 → 自动化」新建「信息」或「电子邮件」自动化，选择「立即运行」，添加「提醒圆圆有新消息」，在「来源 App」填入「信息」「邮件」等对应名称。iOS 27 若提供「通知」触发器，可选择设备列出的 App。请勿选择圆圆作为通知来源，以免循环触发。
3. 收到符合条件的消息后，灵动岛会显示来源名称，锁屏陪伴卡和系统横幅会显示「信息有新消息」等提示。来源为空时显示通用提醒。点实时活动或横幅可回到圆圆并清除提醒。

灵动岛、锁屏陪伴卡和刘海屏预览都显示圆圆本体的一对白色眼睛。长按灵动岛展开后，每点一次手势按钮，圆圆就依次眯眼笑、单眼眨眼或歪头张望。来消息时，展开视图会显示来源 App，点信封可回到圆圆。「设置 → 灵动岛与通知」的刘海屏预览会演示正在陪伴时的张望和眨眼。

快捷指令只需要触发圆圆的动作，不需要传入发件人和消息正文。已有使用 `yuanyuan-pet://message-received` 的快捷指令仍可打开圆圆显示提醒。

## 真机验证

- 性能对比建议在同一台 iPhone 上使用 Release 构建：先观察「陪伴」待机与连续戳脸，再完成一次本地语音对话，结束后停留约 40 秒，再切到后台。用 Xcode 的 CPU 和 Memory 仪表记录待机、播报后和返回首页时的数据；切换「省电显示」后检查边缘光效、手势和表情播放。

- 首次启动时竖着拿手机，应直接进入横屏「自动表情」。观察几个表情换播，再切到「陪伴」、退出并重新打开，确认保留陪伴。左右横屏都试一次。快戳三次，等圆圆恢复后再戳，检查笑、惊讶、生气和回到待机。单独验证戳眼与轻抚。
- 真机试双指左滑和右滑、三指上滑、两个方向快速反转、捏合与系统三指手势；检查短滑回弹不换表情，且不误触摸脸或聊天。启用「减少动态效果」与旁白，验证仍可点选或用辅助功能动作。
- 不配 Key 分别说「我不开心了」「我今天很开心」，然后接着分享一句，检查回复与继续收音。验证麦克风拒绝、主动结束和自然超时。配置 DeepSeek 后再试按分享内容追问。
- 从「玩法」试玩两种触屏互动、扔球、表情秀、夜灯与番茄钟；检查活动能退出、夜灯能一键返回陪伴，以及锁屏后计时仍继续。
- 分开试隔空、摇一摇和拍手；检查权限拒绝提示、退出到后台后不继续使用相机和麦克风。左右横屏各试一次隔空击掌与戳泡泡。
- 打开圆圆并允许通知，使用「试一下消息提醒」，检查「圆圆吧台精灵」横幅。离开 App 后检查岛上的信封和锁屏提示。点实时活动确认信封清除。配置一条信息自动化，在后台和锁屏时各发送一条符合条件的消息，再试关闭灵动岛陪伴、只开消息通知横幅的情况。
