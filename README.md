# 圆圆 · iPhone

圆圆支持 iPhone 竖屏和横屏。普通模式下，轻点或安静等一会儿都能看到本轮的下一个表情，35 个都播过后才重新洗牌。陪伴模式只在待机和轻点时做轻动作。长按圆圆打开「表情与设置」，可以切换模式、播放表情秀或预览单个表情。支持轮换的表情在单独预览时会连播三组。设置和语音按钮默认隐藏，可在「屏幕与按钮」中分别开启。详见[表情模式设计 v2](表情模式设计%20v2.md)。

## 安装到自己的 iPhone

从 GitHub 克隆时，请先安装 [Git LFS](https://git-lfs.com/) 并运行 `git lfs install`。如果已克隆但离线语音模型未下载，在仓库目录运行 `git lfs pull`。

1. 在 Mac 安装完整 Xcode，打开 `DesktopPet.xcodeproj`。项目使用 Swift 6.2 的编译设置，建议使用 Xcode 26 或更新版本。手机最低要求为 iOS 17。
2. 连接并信任 iPhone。如果系统提示，开启手机的「设置 → 隐私与安全性 → 开发者模式」。
3. 在 Xcode 的 `DesktopPet` target 中进入 **Signing & Capabilities**，开启自动签名，并选择你的 Team。若默认 Bundle Identifier 已被占用，请将它改成自己的唯一标识。
4. 在工具栏将运行目标选为自己的 iPhone，点 Run。安装后可直接从手机桌面打开。免费 Personal Team 签名到期后需通过 Xcode 重新安装。

## 番茄钟与扔球接球

- 长按圆圆进入「表情与设置」，在「活动」里打开「番茄钟」或「扔球接球」。主画面顶部会显示番茄钟状态和剩余时间。暂停、继续或结束请回到「表情与设置 → 活动 → 番茄钟」。
- 每轮专注 25 分钟，结束后可开始 5 分钟休息，或再专注一轮。锁屏、切到后台、打开游戏或改用其他显示模式时，计时仍会继续。允许系统通知后，后台到点会提醒。关闭通知后，回到 App 仍可查看结果。
- 在游戏里从球的位置向上划，让球飞向圆圆的接球区，也可以点「投球」。投完三球后查看接到几球，再玩一次或退出。番茄钟运行时打开游戏，回到主画面仍可看到计时。

## 第一批感知与语音

- 长按桌宠，进入「表情与设置 → 互动感知」，可分别开启眼神跟随、手势互动、体感和声音反应，四个开关默认关闭。开启眼神跟随后，把一只手放在前置镜头能看到的位置，缓慢向四边移动，桌宠会跟着手移动。手离开时，桌宠会平滑回到人脸方向或屏幕中央。体感识别倾斜、摇晃和翻面，麦克风识别拍手、吹气和有规律的节拍。
- 第一次打开「手势互动」时允许相机权限，然后回到主画面。张开一只手左右挥，圆圆会挥手。双手食指尖相碰、拇指尖相碰，围成心形，圆圆会露出爱心眼。竖起一只手的大拇指，圆圆会点赞。相机画面在设备上处理。想完全关闭相机感知时，可以同时关闭「眼神跟随」和「手势互动」。
- 在「模式」可选普通、陪伴、电量宠物和夜灯。新用户从普通开始，已有用户保留已保存的模式。普通模式里的充电和录音类表情标为演绎。电量宠物根据 iOS 状态显示充电中或已充满，前台观察到充满时会播放一次满电动作。夜灯使用暖光，可设 15、30 或 60 分钟。
- 「表情秀」提供「元气派对」「反差小剧场」和「看全部」。播放中可以跳过当前动作或退出。结束后回到原模式。
- 在「语音聊天」填入自己的 DeepSeek API Key 并保存，模型留空时使用 `deepseek-flash`。回到圆圆的主画面，向上滑开始说话，再向上滑一次发送。如果开启了语音按钮，也可以按住说话，松开发送。实际录音时，圆圆会切换到「我在听」表情。可以先说「今天有点累」，再试「开夜灯」或「设置 5 分钟倒计时」。夜灯模式暂停录音，可从设置切回陪伴。
- iPhone 负责普通话端侧转写。可以直接说「请你跳一段舞」「给我比个心」「帮我吹几个泡泡」，本地匹配到的指令无需 DeepSeek。配置 DeepSeek 后，普通聊天用转写文字和最近 8 轮以内的对话判断用户情绪，再在 App 里匹配表情。对话历史存于内存，Key 存入本机钥匙串。倒计时可在 App 内查看，允许通知后才有后台提醒。
- 播报使用随 App 安装的普通话女声，在设备上合成。长按圆圆，在「播报音色」里可试听当前音色。DeepSeek 自由聊天需要联网，内置指令和语音播报可离线使用。
- 「语音唤醒与表情音效」可以开启主画面喊名字唤醒。说「嘿，圆圆」，等出现「我在听」后再说指令，也可继续使用上滑或按住麦克风。喊名字唤醒默认关闭，开启后离开主画面会停止监听。
- 「给我唱首歌」和「唱圆圆进行曲」会播放内置的 NOMI 进行曲音轨。目前音轨来自约 9 秒的 ES8 实拍片段。圆圆抱着白线吉他随节拍左右摆，播放期间屏幕常亮，音轨结束时回到中央。可在设置里试听，或点停止按钮结束。 [ES8 实拍参考](https://www.xchuxing.com/video/18600)
- 「表情音效」默认关闭，可随时切换。开启后，可以就地试听，也可以在表情列表里逐个试听。静音模式下仍可播放，音量跟随 iPhone 媒体音量。日常短音效播放时暂停等待唤醒，播完恢复。圆圆进行曲由用户主动播放。

## 真机检查

1. 打开 App 并在两个横屏方向和竖屏检查表情、轻点互动、设置和麦克风入口。确认默认未开启相机和声音反应。
2. 分别开启眼神跟随和手势。把手放在前置镜头前，分别移向上下左右，确认双眼随手接近屏幕四边，移开手后平滑回位。左右移动头部、离开镜头 5 秒，再在离开至少 10 秒后回来。回到普通或陪伴的主画面，等当前动作播完。在竖屏及两个横屏方向验证挥手、点赞、双手比心分别触发圆圆挥手、点赞和爱心眼。测试静止张掌、持续点赞、放下手后再点赞。
3. 开启体感和声音反应。试倾斜、摇晃、扣下和翻回。再试拍一下、连拍两下、吹气、播放节拍清楚的音乐。切到后台检查系统相机和麦克风指示灯。
4. 普通模式下轻点和等待，确认两种方式能推进同一轮。快速点几次，检查动作播完再接下一个。播放表情秀，试跳过、退出和切后台。切到陪伴，检查轻动作和轻点回应。切到电量宠物，检查真实充电状态和满电动作。
5. 第一次上滑唤起语音时授予系统权限，再试说「今天有点累」和「我拿到 offer 了」，检查播报与动作是否对齐。移除 DeepSeek Key 后试「请你跳一段舞」和「别跳舞」，只有前一句触发蹦迪。可在电量宠物模式试「你充满了吗」。
6. 开启相机感知运行 15 分钟，记录发热、电量和帧率。手势及声音反应的识别阈值需要根据真机环境验证。
7. 试听圆圆进行曲，确认能播完和手动停止。打开「喊名字唤醒」后说「嘿，圆圆」，看到「我在听」后说「唱圆圆进行曲」。同时试说「别唱歌」，检查误触发和设置中的上次转写。
8. 长按圆圆，从「表情与设置 → 活动」开始一轮番茄钟，检查主画面计时状态和设置里的暂停、继续、结束。允许通知后锁屏等到点，再回到 App 确认可选择休息或再开一轮。关闭通知权限时，回到 App 仍应显示完成结果。
9. 专注中打开游戏，分别试投中、偏左或偏右、短划和快速连划。确认三球才结算，能再玩或退出，退出后番茄钟继续。进入游戏和专注前先打开手势，检查它们运行期间暂停相机感知，回到日常主画面后可再次挥手、比心、点赞。

动画定义在 `DesktopPet/PetExpression.swift`，绘制在 `DesktopPet/PetFace.swift`，感知与语音的调度在 `DesktopPet/PetDirector.swift`。
