# 圆圆 · iPhone

把 iPhone 放在桌上，让圆圆陪你工作、休息或玩一会儿。支持竖屏和两个横屏方向。无需配置 API Key，就能切换表情、用语音触发常用动作、计时和玩小游戏。

**当前体验版：1.0（构建 5）**。这一版加入了戳眼睛和轻抚、触屏及隔空泡泡与击掌、早安和午饭问候。语音对话支持显示实时转写、重播回复和自定义宠物名字与性格，也可以选配豆包的实时转写和「团子」音色。

## 第一次怎么玩

| 想做什么 | 怎么操作 |
| --- | --- |
| 换表情 | 轻点圆圆，或等它自动切换。普通模式会将 35 个表情播完再洗牌；陪伴模式只做轻动作。 |
| 戳眼睛、摸摸脸 | 点左眼或右眼，圆圆会闭上对应的一侧；横向轻抚眼睛周围，它会跟随手指、眯眼脸红。 |
| 戳泡泡、击掌 | 长按圆圆，选「和圆圆玩」，可用触屏完成。也可以点右下角眼睛并允许相机：伸出食指稍停，再用指尖戳破四颗泡泡；或把掌心停稳，等圆圆举手后向前推。 |
| 说句话 | 点右下角麦克风或向上滑。说完停一会儿会自动发送，圆圆播完回复后继续听。点叉号或说「结束对话」退出。 |
| 开始番茄钟 | 长按 →「活动」→「番茄钟」。专注 25 分钟，结束后可休息 5 分钟或再开一轮。锁屏后继续计时，允许通知后会收到后台提醒。 |
| 扔球接球 | 长按 →「活动」→「扔球接球」。向上划球或点「投球」，三球后结算。专注期间玩游戏，计时会继续。 |

长按打开「表情与设置」，可切换普通、陪伴、电量宠物和夜灯，或在「表情秀」播放节目与预览单个表情。电量宠物会显示真实充电状态；夜灯支持 15、30、60 分钟定时。

「屏幕与按钮」里可开启常驻设置按钮和按住说话按钮。主动问候默认开启：圆圆在普通或陪伴主画面空闲时，会在当地时间 05:00–11:00、11:00–14:00 各问候一次。问候使用本机音色，可在设置里关闭。

「互动感知」中的眼神跟随、手势、体感和声音反应默认关闭。打开手势后，可以挥手、比心、点赞，或张掌后收拢指尖开始对话；体感支持倾斜、摇晃和翻面，声音反应支持拍手、吹气和节拍。「语音唤醒与表情音效」也可单独开启喊名字唤醒、试听表情音效和圆圆进行曲。

## 语音怎么配置

长按圆圆，在「表情与设置 → 语音对话」里可设置名字、性格和云服务。两个 Key 可以独立启用，都保存在 iPhone 钥匙串，可测试连接、替换或移除。

| 配置 | 用途 | 数据怎么处理 |
| --- | --- | --- |
| 不填 Key | 本机转写和播报。可试「给我比个心」「帮我吹几个泡泡」「给我唱首歌」。 | 本地匹配动作；开启喊名字唤醒后，唤醒监听也在本机完成。 |
| DeepSeek API Key | 开启自由聊天。留空模型名时使用应用内默认值 `deepseek-flash`。 | 自由聊天会发送转写文字和最多 8 轮近期对话给 DeepSeek。历史存于 App 内存。 |
| 豆包语音 API Key | 开启云端实时转写和「团子」音色。在[豆包语音控制台](https://console.volcengine.com/speech/new/setting/apikeys?projectName=default)的同一项目开通「流式语音识别 2.0（小时版）」与「语音合成 2.0」，填入 Key 后点「验证并保存」。 | 主动录音和待播报文本由火山引擎处理。验证会发送短静音和固定试听文本；播报失败会尝试本机音色。 |

相机画面只在设备上处理。若要停止相机，关闭主画面的隔空互动，以及设置中的眼神跟随和手势互动。

## 安装到自己的 iPhone

需要一台装有 Xcode 26 或更新版本的 Mac，以及运行 iOS 17 或更新版本的 iPhone。当前提供 Xcode 源码安装。

1. 先安装 [Git LFS](https://git-lfs.com/)，再下载源码和离线语音模型：

   ```bash
   git lfs install
   git clone https://github.com/haozi-techhub/yuanyuan-iphone-pet.git
   cd yuanyuan-iphone-pet
   git lfs pull
   open DesktopPet.xcodeproj
   ```

2. 连接并信任 iPhone。若系统提示，在 iPhone 的「设置 → 隐私与安全性」开启开发者模式。
3. 在 Xcode 的 `DesktopPet` target 中进入 **Signing & Capabilities**，启用自动签名并选自己的 Team。如果默认 Bundle Identifier 不可用，改成自己的唯一标识。
4. 在 Xcode 工具栏选择自己的 iPhone，点 Run。免费 Personal Team 签名到期后，需要通过 Xcode 重新安装。

## 真机验证

- 竖屏和两个横屏方向各试一次轻点、戳眼睛、横向轻抚、触屏及隔空泡泡和击掌。切到后台时检查相机和麦克风指示灯。
- 不配置 Key，试一次本机语音动作指令；配置 DeepSeek 后再试两轮自由聊天。配置豆包后试听音色，并验证实时转写、停顿发送、播报后继续收音、退出和重播回复。
- 开始一轮番茄钟，锁屏等到点，检查通知与回到 App 后的结果。专注时玩三球，检查结算并确认计时持续。
- 开启眼神跟随、手势、体感和声音反应，分别试一次。持续开启相机 15 分钟，观察发热、耗电和动作流畅度。
